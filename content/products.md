WizTools.org has a collection of OpenSource tools and libraries focused mostly on programmer productivity.

## Tools

- [RESTClient](https://github.com/wiztools/rest-client): Tool to test HTTP communication / RESTful WebServices.
- [Cli Tools Bundle](http://cli-bundle.wiztools.org/): Bundle of cli-tools from WizTools for Windows.
- [Regular Expression Tester](https://github.com/wiztools/re-test): Java Swing tool to quickly test RE patterns.
- [Wiz WebServer](https://bitbucket.org/wiztools/wiz-webserver): A tiny WebServer written in Java. Useful for Ajax testing.
- [StaGen](https://github.com/wiztools/stagen): Static site generator written in Java 8 supporting StringTemplate 4 for template rendering, Markdown for content and JSON for configuration.
- [CSS Import Resolver](https://github.com/wiztools/css-import-resolver): Generate optimized CSS by including @import files inline.
- [Multicast Tool](https://github.com/wiztools/multicast-tool): Tool to test multicast communication.
- [S3 Upload](https://github.com/wiztools/s3upload-cli): Tool to upload files to S3 bucket.
- [Amazon SES Cli](https://github.com/wiztools/amazon-ses-cli): Tool to send email using AWS SES.
- [EC2 Control](https://github.com/wiztools/ec2-control): Cli tool to start/stop AWS EC2 instances.
- [OpsWorks Control](https://github.com/wiztools/opsworks-control): Cli tool to start/stop AWS OpsWorks stacks/instances.
- [Markdown-to-HTML](https://github.com/wiztools/markdown2html): Convert MD files to HTML.
- [JFind](https://bitbucket.org/wiztools/jfind): Tool to search from where in the CLASSPATH specified class file is available.
- [Classloader Servlet](https://github.com/wiztools/classloader-servlet): Servlet tool to aid in debugging classpath / classloader issues in Java web applications.
- [Text Encoding Util](https://github.com/wiztools/text-encoding-util): Cli utility to transform text from one encoding to another, and to test if a text file conforms to charset specified by a particular encoding.
- [Date Arithmetic](https://github.com/wiztools/date-arithmetic): Add / subtract years / months / days to a date and get result.
- [Binary Calculator](https://github.com/wiztools/bc): Tool inspired by Unix `bc`.
- [Tree](https://github.com/wiztools/tree): Inspired by Unix `tree`.
- [Base64 Cli](https://github.com/wiztools/base64-cli): Compute Base64 encoding of any file.
- [JWget](https://github.com/wiztools/jwget): Tool inspired by Unix `wget`.
- [Portscanner](https://github.com/wiztools/portscanner-cli): A port-scanning tool.
- [Digest Hex Util](https://github.com/wiztools/digest-hex-util): GUI tool to compute hex-encoded checksum (md5 / sha) for a given string.
- [Checksum Compute](https://github.com/wiztools/checksum-compute): GUI tool to compute SHA and MD5 checksum of given file.
- [Json Validator](https://github.com/wiztools/json-validator): Cli Json validator and formattor.
- [XML Validator](https://github.com/wiztools/xml-validator): Cli tool to validate correctness of your XML against a schema.
- [Xslt Transform](https://github.com/wiztools/xslt-transform): Tool to transform XMLs using XSL stylesheets.
- [Xsd Gen](https://github.com/wiztools/xsd-gen): Command-line tool written in Java for generating XSD from an XML.
- [Pomodoro Timer](https://github.com/wiztools/pomodoro-timer-ui): Pomodoro Timer written in Java Swing.
- [Timezone Converter](https://github.com/wiztools/timezone-converter): Cross platform Timezone Converter tool.
- [Screen Color Picker](https://github.com/wiztools/screen-color-picker): Java cli tool to pick colors from screen.
- [URL Encoder](https://github.com/wiztools/urlencode-ui): GUI tool for encoding / decoding URL special characters.
- [JavaDoc Jar Viewer](https://github.com/wiztools/javadoc-jar-viewer): Cli tool to open Java doc packaged as Jar in browser.
- [Java System Property Cli](https://github.com/wiztools/system-property-cli): Tool to list Java system properties.
- [Java SimpleDateFormat Tester](https://github.com/wiztools/java-simpledateformat-tester): GUI tool to test SimpleDateFormat expression.
- [Any Url Http Server](https://github.com/wiztools/anyurlhttpserver): An API mocking tool.
- [Bulk Mailer](https://github.com/wiztools/bulk-mailer): Bulk mailer script written in Perl.
- [WizCrypt](https://github.com/wiztools/wizcrypt): File encryption app and library.

## Libraries

- [moneylib](https://github.com/wiztools/moneylib): Golang library to represent money value.
- [wiz-cliparse](https://github.com/wiztools/wiz-cliparse): Cli argument parsing lib that Node deserves.
- [oEmbed Java API](https://bitbucket.org/wiztools/oembed): A clean API to access and parse oEmbed services.
- [Pagination Lib](https://bitbucket.org/wiztools/pagination-lib): A Java library to paginate Collections.
- [Commons Lib](https://bitbucket.org/wiztools/wiztools-commons-lib): This is a rich collection of commonly used convenience classes and data-structures for Java.
- [Feed Lib](https://bitbucket.org/wiztools/feed-lib): Abstraction library for RSS and Atom parsing.
- [Cache Lib](https://github.com/wiztools/cache-lib): Abstraction library for Java cache providers.
- [Ant XPath Task](https://github.com/wiztools/ant-xpath-task): Ant task for executing XPath expression on XML and storing it as a property.
